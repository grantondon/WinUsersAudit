# WUA_Merge

`WUA_Merge.py` объединяет результаты WinUsersAudit **1.0.1** из ZIP-архивов
в единый файл Excel `WUA_Merge.xlsx`.

## Требования и установка

- Linux;
- Python 3.9 или новее;
- пакет `openpyxl`.

Установка зависимости:

```bash
python3 -m pip install -r requirements.txt
```

## Размещение и запуск

Поместите ZIP-архивы WinUsersAudit рядом со скриптом либо в его вложенные
каталоги. Исходные ZIP и CSV не изменяются, CSV из архивов на диск не
распаковываются.

Запуск без аргументов:

```bash
python3 WUA_Merge.py
```

Результат создаётся рядом со скриптом: `WUA_Merge.xlsx`.

## Листы Excel

Создаются листы `int`, `netstat`, `route`, `software`, `user` и `summary`.
Пять первых содержат объединённые одноимённые CSV; исходный порядок и названия
столбцов сохранены. Перед ними добавляется столбец `Папка`.

Если лист достигает лимита Excel (1 048 576 строк с заголовком), создаётся
следующий лист того же типа: например, `netstat_2`.

`summary` содержит дату и время формирования, счётчики архивов и строк,
созданные листы, статистику по каталогам и сообщения об ошибках,
предупреждениях и успешной обработке.

## Столбец «Папка»

Значение — относительный путь от папки скрипта до папки, содержащей ZIP;
разделитель всегда `/`. Имя ZIP не включается. Для ZIP рядом со скриптом
значение пустое.

Например, для `Отдел ИБ/Серверы/PC03.zip` значение будет
`Отдел ИБ/Серверы`.

## Проверки и ограничения

Скрипт проверяет целостность ZIP, UTF-16 LE с BOM и строгую декодировку CSV,
точное количество и названия колонок текущего формата WinUsersAudit 1.0.1.
Повреждённый ZIP, отсутствующий CSV, ошибочная кодировка или несовместимая
структура не прерывают обработку других архивов. Несовместимый CSV целиком
пропускается, чтобы исключить смещение столбцов; причина фиксируется на листе
`summary`.

Текстовые значения, начинающиеся с `=`, `+`, `-` или `@`, записываются как
текст, без выполнения формул Excel. Скрипт рассчитан только на пять CSV,
создаваемых WinUsersAudit 1.0.1; диагностический журнал в объединение не
входит.
