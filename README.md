# WinUsersAudit — unified-report

Экспериментальная версия аудита Windows, сохраняющая результат одного запуска в
единый структурированный файл WUA1. Сборщик ничего не изменяет в системе.

> Ветка main содержит стабильную классическую версию, формирующую отдельные CSV.
>
> Ветка unified-report содержит экспериментальную версию, формирующую единый
> структурированный лог и использующую отдельный парсер.

Ветки развиваются независимо и не должны автоматически объединяться.

## Файлы и требования

- WinUsersAudit.vbs — сборщик;
- parse_wua_logs.py — парсер множества логов;
- tests/test_parse_wua_logs.py — автоматические тесты;
- WinUsersAudit_README.txt — инструкция для старых Windows.

Целевые ОС сборщика: Windows XP SP2, Windows Server 2003 и более поздние
Windows. Используются штатные WSH/VBScript, WMI, ADSI WinNT, COM, secedit.exe,
netstat.exe, route.exe, WinHTTP, HNetCfg.FwPolicy2 и резервный HNetCfg.FwMgr.
PowerShell, .NET, WMIC, curl, Python и сторонние программы на проверяемом ПК не
нужны. Для полного результата рекомендуется запуск с правами администратора.

## Запуск сборщика

    cd /d C:\Audit
    cscript //nologo WinUsersAudit.vbs

Результат рядом со скриптом:

    <hostname>_YYYYMMDD_HHMMSS.wua.log

Во время работы используется файл с окончанием wua.partial. После записи END и
успешного закрытия он переименовывается в wua.log. При аварии partial
сохраняется. Совпавшее имя не перезаписывается: добавляется числовой суффикс.

Классические user.csv, int.csv, route.csv, netstat.csv, diag.log и ZIP в этой
ветке по умолчанию не создаются.

### Ключи

    cscript //nologo WinUsersAudit.vbs /debug
    cscript //nologo WinUsersAudit.vbs /nolog

- обычный запуск и /debug сохраняют подробные INFO;
- /nolog не отключает основной лог: FILE, SCHEMA, DATA, WARNING, ERROR и END
  сохраняются, но необязательные INFO опускаются;
- при одновременных /debug и /nolog приоритет имеет /nolog;
- неизвестный ключ фиксируется как WARNING.

## Формат WUA1

Кодировка — UTF-16 LE с BOM, строки — CRLF, разделитель — точка с запятой.
Каждое значение заключено в двойные кавычки; внутренняя кавычка удваивается.
Каждая физическая строка — одна запись и начинается с WUA1.

Перед CSV-кодированием обратный слеш удваивается, CR представляется как
backslash-r, LF как backslash-n, табуляция как backslash-t. Парсер выполняет
обратное преобразование.

### FILE

Первая строка содержит версию формата, идентификатор запуска, hostname, время
начала, версии сборщика, ОС и WSH, часовой пояс, учётную запись и административные
права.

    "WUA1";"FILE";"1";"PC-01_20260909_143025";"PC-01";"2026-09-09T14:30:25+03:00";"WinUsersAudit 4.1";"Microsoft Windows 10";"10.0.19044";"cscript.exe 5.812";"+03:00";"PC-01\Admin";"Да"

### SCHEMA и DATA

Перед первой DATA каждого типа один раз записывается SCHEMA.

    "WUA1";"SCHEMA";"USER";"2";"Идентификатор запуска";"Время сбора";"Компьютер или домен";...
    "WUA1";"DATA";"USER";"2";"PC-01_20260909_143025";"2026-09-09T14:30:27+03:00";...

Версии схем независимы для каждого типа. В текущей версии USER и PING используют
схему 2, остальные типы — схему 1. Число значений DATA должно совпадать со
SCHEMA. Парсер читает схему из лога и объединяет разные версии по именам колонок.

### EVENT

    "WUA1";"EVENT";"1";"PC-01_20260909_143025";"2026-09-09T14:30:29+03:00";"WARNING";"FIREWALL";"FwPolicy2 недоступен, используется FwMgr";"429";"ActiveX component can't create object"

Уровни: INFO, WARNING, ERROR. Подсистемы: STARTUP, SYSTEM, USER,
PASSWORD_POLICY, SECEDIT, INTERFACE, ROUTE, FIREWALL, CONNECTION, PING, HTTP,
FILE, FINISH.

### END

    "WUA1";"END";"PC-01_20260909_143025";"COMPLETE_WITH_WARNINGS";"2026-09-09T14:31:12+03:00";"SYSTEM=1";"USER=8";"WARNING=2";"ERROR=0"

Статусы: COMPLETE, COMPLETE_WITH_WARNINGS, PARTIAL, FAILED. Отказ раздела не
останавливает остальные разделы и приводит как минимум к PARTIAL.

## Типы данных

| Тип | Содержание |
|---|---|
| SYSTEM | ОС, сборка, SP, архитектура, WSH, пути, учётная запись, права, домен |
| USER | 13 полей пользователя, пять параметров парольной политики, идентификатор и время |
| PASSWORD_POLICY | параметры secedit, код, INF, источник и достоверность |
| INTERFACE | все адаптеры и 19 сетевых полей; IPv6 исключён |
| ROUTE | IPv4-маршруты, интерфейс, метрика и источник |
| FIREWALL_PROFILE | профили, действия, уведомления, служба и COM-источник |
| CONNECTION | IPv4 TCP/UDP и процесс; командная строка не собирается |
| PING | одна итоговая строка для каждого из пяти IPv4-адресов |
| HTTP | результат каждого из пяти URL |
| EVENT | диагностика, предупреждения и ошибки |

Возраст пароля читается через ADSI WinNT PasswordAge в дочернем cscript с
тайм-аутом 30 секунд. Формат: N дней HH часов MM минут SS секунд. Ноль — допустимое
значение, а не признак отсутствия пароля.

- Не задан — параметр существует, но явно не настроен.
- Не определено — источник не предоставил достоверное значение.
- Не применимо — параметр неприменим к данной записи.

## Парсер

На компьютере обработки требуется Python 3, только стандартная библиотека.
Работает в Windows и Linux, ищет логи рекурсивно и не изменяет их.

    python3 parse_wua_logs.py <папка_с_логами> <папка_результатов>
    python3 parse_wua_logs.py logs result --all
    python3 parse_wua_logs.py logs result --latest
    python3 parse_wua_logs.py logs result --all --include-partial

- --all выгружает все допустимые запуски и является режимом по умолчанию;
- --latest выбирает по FILE и END последний полный запуск каждого hostname;
- --include-partial разрешает partial, незавершённые log и неполные статусы;
- --all и --latest взаимоисключающие.

Создаются и перезаписываются. Данные SYSTEM остаются в исходном логе и
учитываются в runs.csv, но отдельный systems.csv не формируется:

    users.csv
    password_policies.csv
    interfaces.csv
    routes.csv
    firewall.csv
    netstat.csv
    ping.csv
    http.csv
    diagnostics.csv
    runs.csv
    parser_errors.csv

Все CSV — UTF-16 LE с BOM, CRLF, точкой с запятой, кавычками вокруг всех
значений и заголовком даже без данных. Добавляются служебные поля запуска.
Разные схемы объединяются в порядке первого появления; отсутствующее поле
получает Не определено. runs.csv содержит все найденные запуски и причину
выбора или пропуска. parser_errors.csv изолирует ошибки отдельных строк/файлов.

## Тестирование и ограничения

    python3 -m unittest discover -s tests -v

Тесты покрывают завершённые и незавершённые логи, partial, latest, разные схемы,
неизвестные типы, повреждённые DATA, Unicode, специальные символы, пустые
значения, подкаталоги, BOM, CRLF, отсутствие пустых строк и смещения колонок.

На каждой целевой Windows:

1. Запустить из административной командной строки без ключей.
2. Проверить переход partial в один log и наличие FILE, SCHEMA, DATA, EVENT, END.
3. Повторить с /nolog, неизвестным ключом и отказом отдельной подсистемы.
4. Проверить парсер в режимах all, latest и include-partial.

Статическая проверка не подтверждает совместимость с XP SP2/Server 2003 —
нужен реальный запуск. Недоступное свойство не трактуется как отключённое.
netstat является снимком, поэтому процесс может завершиться до WMI-обогащения.
Проверка прав через net session может вернуть Не определено при недоступной
службе. Сборщик не читает пароли и не определяет факт их наличия.
